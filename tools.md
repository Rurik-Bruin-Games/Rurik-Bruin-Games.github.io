## 🛠️ Tools & Setup

At **Rurik Bruin Games**, we keep C64 game development as native as possible—writing code, designing sprites, and composing audio directly on real Commodore 64 hardware or inside cycle-accurate emulation. Our Linux workstation stays strictly in a supporting role for emulation testing and pushing site updates.

---

### 🖥️ Target Hardware

* **[Commodore 64 Ultimate (C64U Slimline)](https://commodore.net)** — Our primary target platform and real-hardware testbed for cycle accuracy, REU memory expansion, and authentic SID playback.

---

### 🕹️ Native C64 Development, Art & Audio

* **[Vision BASIC](https://visionbasic.net)** — Our core game engine, compiler, and asset suite. It extends classic C64 BASIC with fast compiled machine-code output, inline 6510 assembly, and native sprite/character editors (including **The Spreditor**) so all game logic and pixel work stays right on the C64.
* **[SID-Wizard](https://csdb.dk)** — Native C64 music tracker by Hermit used to compose our 3-channel SID soundtracks and sound effects directly on C64 hardware or inside VICE.

---

### 🐧 Emulation & Host Workstation

* **[VICE (Versatile Commodore Emulator)](https://sourceforge.io)** — Specifically `x64sc`, used for rapid emulation testing, REU configuration checks, and running native C64 tools alongside real hardware verification.
* **[Pop!_OS](https://system76.com)** — Our Linux desktop OS, used strictly as the host environment for running VICE and pushing Markdown devlogs and site updates to Git.

---

### 🌐 Web, Hosting & Distribution

* **[GitHub](https://github.com) & [GitHub Pages](https://github.com)** — Version control for our game source code and static hosting for `rurikbruin.com` (built with [Jekyll](https://jekyllrb.com)).
* **[itch.io](https://itch.io)** — Distribution hub for downloadable `.d64` disk images, `.prg` binaries, and browser-playable demos.
* **[Porkbun](https://porkbun.com)** — Domain registrar for `rurikbruin.com`.
* **[Gmail](https://google.com)** — Studio correspondence (`contact@rurikbruin.com`), press inquiries, and player feedback.
